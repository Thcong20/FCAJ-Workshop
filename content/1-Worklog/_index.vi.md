Trong suốt thời gian thực tập từ 20/04/2026 đến 12/07/2026, tôi đã thực hiện các công việc và ghi chép nhật ký công việc chi tiết theo từng tuần:

- **[Tuần 1 (20/04 – 26/04)](1.1-week1/):** Tạo tài khoản AWS, tìm hiểu tổng quan về Cloud Computing, các dịch vụ cơ bản và thiết lập bảo mật qua AWS IAM.
- **[Tuần 2 (27/04 – 03/05)](1.2-week2/):** Thực hành các dịch vụ cốt lõi: Amazon VPC, EC2, S3, AWS Lambda (Serverless), API Gateway, DynamoDB và CloudWatch Logs.
- **[Tuần 3 (04/05 – 10/05)](1.3-week3/):** Tìm hiểu kiến trúc dự án Budget Tracker, cấu trúc ReactJS, Cognito user pools, SNS, SQS.
- **[Tuần 4 (11/05 – 17/05)](1.4-week4/):** Tìm hiểu DynamoDB Single Table Design, kết nối API qua Axios, tìm hiểu CDN CloudFront và Route53.
- **[Tuần 5 (18/05 – 24/05)](1.5-week5/):** Hỗ trợ lập trình backend Lambda handlers (ASP.NET Core on Lambda), tích hợp Google Gemini API để tự động phân loại chi tiêu.
- **[Tuần 6 (25/05 – 31/05)](1.6-week6/):** Hỗ trợ test authentication Cognito, Recharts dashboard và API budgets.
- **[Tuần 7 (01/06 – 07/06)](1.7-week7/):** Hỗ trợ phát triển chính thức dự án, chatbot AI, hệ thống S3 receipts storage, email notification SNS.
- **[Tuần 8 (08/06 – 14/06)](1.8-week8/):** Hỗ trợ lập trình frontend chatbot AI, theo dõi metrics qua CloudWatch và chỉnh sửa UI budgets.
- **[Tuần 9 (15/06 – 21/06)](1.9-week9/):** Kiểm tra API transactions, upload receipts lên S3, tìm hiểu quy trình CI/CD deployment.
- **[Tuần 10 (22/06 – 28/06)](1.10-week10/):** Hỗ trợ test API reports, tối ưu hóa giao diện dashboard và responsive UI.
- **[Tuần 11 (29/06 – 05/07)](1.11-week11/):** Tham gia kiểm thử hệ thống tích hợp tổng thể (integration testing), tối ưu hóa API và kiểm tra SNS email delivery.
- **[Tuần 12 (06/07 – 12/07)](1.12-week12/):** Rà soát hệ thống, sửa lỗi nhỏ giao diện, tối ưu hóa database, và hoàn thành báo cáo thực tập tốt nghiệp.

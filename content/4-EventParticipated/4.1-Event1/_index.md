# EVENT REPORT: FCAJ MEETUP - 13/06/2026

### 1. Purpose and Significance
- **Purpose:** Connect with the cloud engineering community, study real-world solutions for Scalable Systems, and learn about infrastructure optimization on AWS.
- **Significance:** Translates college theory into real-world software engineering mindset and guides solving complex technical issues.

### 2. Speakers
- **Mr. Dat & Mr. Cuong:** Cloud Solution Architects.
- **Mr. Hoang Trong:** Senior Systems Engineer (Performance Optimization).
- **Kien & Tho:** Technical representatives presenting real-world project deployments.
- **Hieu Nghi:** Host.

### 3. Key Sharing Highlights
#### 3.1 System Design & Optimization (Case Study: URL Shortening)
- **Problem:** Designing a high-load, low-latency URL shortener service.
- **Solution:** Leveraging AWS Serverless architecture with DynamoDB (high-speed Key-Value store), API Gateway, and AWS Lambda for autoscaling and cost optimization.

#### 3.2 Modern Design Mindset
- **Loose Coupling:** Shifting from sync REST calls to Event-driven Architecture.
- **Caching Strategy:** Reducing database load and latency.

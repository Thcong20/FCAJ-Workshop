# REPORT: FCAJ MEETUP - 25/07/2026 (SESSION 2)

### 1. Purpose and Significance of Participation
- **Purpose:** Deep dive into Operations (CloudWatch logs, metrics monitoring) and Cloud Security (IAM Least Privilege, AWS WAF rules, CI/CD automated deployment).
- **Significance:** Define standard DevOps practices and maintain enterprise-grade security compliance configurations on **Budget Tracker** application layers.

### 2. Guest Speakers List
- **Mr. Nguyen Gia Hung:** AWS Solution Architect, Head Mentor of FCAJ.
- **Mr. Hoang Trong:** Senior Cloud Engineer, cloud security specialist.
- **CCK Team Members:** Discussing CI/CD pipelines configurations and security audit.

### 3. Summary of Key Sessions
#### 3.1 System Monitoring and Logs Management (AWS CloudWatch)
- **Solution:** Create custom CloudWatch Dashboards tracing EC2 metrics and AWS Lambda execution durations/errors.
- **Optimization:** Configure Log Retention policies to 14 days instead of infinite storage to minimize unnecessary logging costs.

#### 3.2 Cloud Infrastructure Security and CI/CD Pipelines
- **Security:** Configure rules on AWS WAF to secure API Gateway endpoints from SQL Injection (SQLi) and Cross-Site Scripting (XSS). Enforce strict IAM Roles configurations under Least Privilege principles.
- **CI/CD:** Construct GitHub Actions workflows to auto-build, run backend unit tests, and deploy C# zip codes to AWS Lambda.

### 4. Knowledge and Skills Acquired
- **Knowledge:** Gain deep insights on logs management, CloudWatch Alarms triggers, and WAF rules. Master automated continuous integration/deployment pipeline patterns.
- **Skills:** Ability to protect cloud resources and automate delivery steps.

# REPORT: FCAJ MEETUP - 25/07/2026 (COUNTED FOR 2 SESSIONS)

### 1. Purpose and Significance of Participation
- **Purpose:** Analyze Generative AI (Gemini API) integration, NoSQL database design (DynamoDB Single Table Design), cloud observability (CloudWatch), CI/CD pipelines, and cloud security (AWS WAF, IAM Least Privilege).
- **Significance:** Leverage expert insights to build automated delivery pipelines, optimize data layouts, and protect **Budget Tracker** application layers.

### 2. Guest Speakers List
- **Mr. Nguyen Gia Hung:** AWS Solution Architect, Head Mentor of FCAJ.
- **Mr. Hoang Trong:** Senior Cloud Engineer, database and cloud security expert.
- **CCK Team Members:** Discussing design options and presenting technical milestones.

### 3. Summary of Key Sessions

#### 3.1 Generative AI & DynamoDB Optimizations (Session 1 Content)
- **Generative AI:** Integrate **Google Gemini API** with AWS Lambda to parse raw user text into structured JSON categories.
- **Single Table Design:** Consolidate Users, Transactions, and Budgets into one DynamoDB table. Map partition and sort keys with custom GSIs to avoid full table scans and improve speeds.

#### 3.2 Cloud Operations, Security & CI/CD Pipelines (Session 2 Content)
- **Monitoring (AWS CloudWatch):** Setup observable dashboards tracking CPU/RAM and configure log retention rules to 14 days to minimize logging costs.
- **Security & CI/CD:** Apply WAF filters on API Gateway protecting against SQLi/XSS. Author GitHub Actions workflows to auto-test and deploy backend Lambdas.

### 4. Knowledge and Skills Acquired
- **System Thinking:** Combining Serverless compute, NoSQL layouts, and LLM endpoints into one decoupled architecture.
- **Execution Skills:** Hardening endpoints security, automating software delivery steps (CI/CD), and configuring cloud metrics/alarms.

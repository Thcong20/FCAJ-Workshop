# REPORT: FCAJ MEETUP - 25/07/2026 (SESSION 1)

### 1. Purpose and Significance of Participation
- **Purpose:** Research and discuss Generative AI technologies and non-relational database optimization methods (NoSQL Single Table Design) on AWS.
- **Significance:** Absorb hands-on experience from Mentors to optimize AI transaction categorization features for the **Budget Tracker** project.

### 2. Guest Speakers List
- **Mr. Nguyen Gia Hung:** AWS Solution Architect, Head Mentor of FCAJ.
- **Mr. Hoang Trong:** Senior Cloud Engineer, database solutions expert.
- **CCK Team Members:** Presenting progress reports and AI integration demos.

### 3. Summary of Key Sessions
#### 3.1 Generative AI in Fintech Applications
- **Technology:** Leverage **Google Gemini API** combined with AWS Lambda to process and auto-categorize financial logs based on raw input string text.
- **Solution:** Design optimized prompts for AI to return formatted JSON outputs, making charts rendering on frontend smooth.

#### 3.2 Database Optimization via DynamoDB Single Table Design
- **Methodology:** Instead of multiple relational tables, merge all entities (Users, Transactions, Budgets) into a single table to minimize write/read operations and save cloud costs.
- **Techniques:** Establish clear PK/SK schemas and configure Global Secondary Indexes (GSIs) to enable fast dynamic query lookups.

### 4. Knowledge and Skills Acquired
- **Knowledge:** Understand call pricing structures and performance optimizations of Gemini API. Master NoSQL Single Table Design query patterns.
- **Skills:** Ability to design optimal partition keys and sorting keys for large-scale data indexing.

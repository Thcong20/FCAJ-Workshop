# Taking AI to Next Level: Claude Sonnet 5 is Now Available on AWS Bedrock

Anthropic has officially launched Claude Sonnet 5 on Amazon Bedrock. It provides a sweet spot balancing intelligence (near Opus), execution speed, and cost efficiency, suited for production at scale.

![Claude Sonnet 5](/images/blog/blog3.png)

### Key Points:
- Provides top-tier intelligence with advanced coding capabilities and automated workflow support.
- Serves as the backbone for Autonomous Agents requiring multi-step tool use.
- Excels in Structured Reasoning, data analytics, and reporting.
- Compliance and regional data residency are natively supported on AWS.
